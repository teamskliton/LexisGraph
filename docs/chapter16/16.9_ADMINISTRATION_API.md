# 16.9 Administration API

---

# 16.9.1 Purpose

The Administration API provides privileged endpoints for managing the LexisGraph platform. It enables Super Administrators to oversee organizations, users, legal knowledge ingestion, AI configuration, background jobs, platform health, and system-wide settings.

Administrative operations shall be restricted to authorized Super Administrators and fully audited.

---

# 16.9.2 Objectives

The Administration API shall:

- Manage organizations.
- Manage platform users.
- Monitor AI jobs.
- Manage legal sources.
- Configure AI models.
- Monitor platform usage.
- Manage system settings.
- Maintain auditability.

---

# 16.9.3 Base Endpoint

```
/api/v1/admin
```

---

# 16.9.4 Administration Domains

The Administration API shall manage:

```
Organizations

Users

Legal Sources

Knowledge Base

Background Jobs

AI Models

Audit Logs

Platform Settings

System Statistics
```

---

# 16.9.5 Organization Management

## List Organizations

```
GET /admin/organizations
```

Supports:

- Pagination
- Search
- Filtering

---

## Get Organization

```
GET /admin/organizations/{organization_id}
```

Returns organization details.

---

## Suspend Organization

```
PATCH /admin/organizations/{organization_id}/suspend
```

Suspended organizations shall lose access until restored.

---

## Restore Organization

```
PATCH /admin/organizations/{organization_id}/restore
```

Restores suspended organizations.

---

## Delete Organization

```
DELETE /admin/organizations/{organization_id}
```

Soft delete only.

Historical data shall remain preserved.

---

# 16.9.6 User Administration

## List Platform Users

```
GET /admin/users
```

Returns users across all organizations.

---

## Lock User

```
PATCH /admin/users/{user_id}/lock
```

Locked users cannot authenticate.

---

## Unlock User

```
PATCH /admin/users/{user_id}/unlock
```

Restores user access.

---

## Reset User Password

```
POST /admin/users/{user_id}/reset-password
```

Generates a password reset request.

---

# 16.9.7 Legal Knowledge Administration

## View Legal Sources

```
GET /admin/legal/sources
```

---

## Trigger Knowledge Sync

```
POST /admin/legal/sync
```

Starts synchronization of configured legal sources.

---

## Rebuild Knowledge Graph

```
POST /admin/legal/rebuild
```

Rebuilds Neo4j graph.

---

## Reindex Embeddings

```
POST /admin/legal/reindex
```

Recreates vector embeddings.

---

# 16.9.8 AI Administration

## List AI Models

```
GET /admin/ai/models
```

Returns configured LLMs.

---

## Update Default Model

```
PATCH /admin/ai/models/default
```

Request

```json
{
    "provider": "OpenAI",
    "model": "gpt-5.5"
}
```

---

## View AI Usage

```
GET /admin/ai/usage
```

Returns:

- Token Usage
- API Calls
- Average Response Time
- Cost Estimates

# 16.9.10 Audit Logs

```
GET /admin/audit
```

- Search
- Date Range
- User
- Organization
- Event Type

# 16.9.11 Platform Settings

Administrators may configure:

- Maximum Upload Size
- Supported File Types
- AI Rate Limits
- Default Jurisdiction
- Retention Policies
- Background Worker Limits
- Feature Flags

Configuration changes shall take effect without requiring application restarts where technically feasible.

# 16.9.15 Audit Events

The platform shall record:

- Organization Suspended
- Organization Restored
- User Locked
- User Unlocked
- Knowledge Sync Started
- Knowledge Graph Rebuilt
- Embeddings Reindexed
- AI Model Changed
- Platform Settings Updated

Administrative actions shall never be deletable.

---

# 16.9.16 Security

The Administration API shall:

- Require Super Administrator privileges.
- Enforce Multi-Factor Authentication (when enabled).
- Log every administrative action.
- Prevent privilege escalation.
- Require HTTPS.
- Protect sensitive configuration values.
- Never expose secrets through API responses.

---

# 16.9.17 Future Enhancements

The API shall support:

- Multi-region administration
- Platform billing management
- Feature rollout management
- Usage quotas
- Tenant migration
- Disaster recovery controls
- Platform maintenance mode

---

# 16.9.18 Acceptance Criteria

The Administration API shall be considered complete when:

✓ Organizations can be managed.

✓ Platform users can be administered.

✓ Knowledge synchronization is supported.

✓ AI configuration is manageable.

✓ Background jobs can be monitored.

✓ Platform statistics are available.

✓ Administrative actions are fully audited.

---

# 16.9.19 Summary

The Administration API provides centralized platform management capabilities for LexisGraph. It enables Super Administrators to oversee organizations, users, legal knowledge ingestion, AI infrastructure, background processing, and system configuration while ensuring strong security, complete auditability, and reliable platform operations.
