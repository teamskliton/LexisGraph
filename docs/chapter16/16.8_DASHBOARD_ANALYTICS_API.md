# 16.8 Dashboard & Analytics API

---

# 16.8.1 Purpose

The Dashboard & Analytics API provides aggregated organizational metrics, compliance insights, activity summaries, and analytical data required by the LexisGraph dashboard. It enables users to quickly assess organizational compliance status without manually reviewing individual reports.

The API shall provide read-only analytical data optimized for dashboard rendering.

---

# 16.8.2 Objectives

The Dashboard API shall:

- Display compliance overview.
- Show policy statistics.
- Present compliance trends.
- Display AI analysis summaries.
- Monitor background jobs.
- Show recent activities.
- Provide organization insights.
- Support dashboard widgets.

---

# 16.8.3 Base Endpoint

```
/api/v1/dashboard
```

---

# 16.8.4 Dashboard Architecture

```
PostgreSQL

↓

Analytics Service

↓

Aggregation Layer

↓

Dashboard API

↓

Frontend Dashboard
```

The Dashboard API shall consume aggregated data and shall not execute AI analysis.

---

# 16.8.5 Dashboard Overview

## Get Dashboard Summary

```
GET /dashboard/summary
```

Returns high-level organizational metrics.

Example Response

```json
{
    "total_policies": 42,
    "completed_reports": 18,
    "pending_analysis": 3,
    "overall_compliance_score": 84
}
```

---

## Compliance Score

```
GET /dashboard/compliance-score
```

Returns overall compliance score.

Example

```json
{
    "score": 84,
    "status": "Good"
}
```

---

## Policy Statistics

```
GET /dashboard/policies
```

Returns:

```json
{
    "uploaded": 42,
    "processing": 2,
    "completed": 40,
    "archived": 6
}
```

---

## Analysis Statistics

```
GET /dashboard/analysis
```

Returns:

```json
{
    "completed": 34,
    "running": 1,
    "queued": 2,
    "failed": 0
}
```

---

## Recent Activities

```
GET /dashboard/activity
```

Returns recent platform events.

Example

```json
{
    "activities": [
        {
            "type": "REPORT_GENERATED",
            "timestamp": "...",
            "user": "John Doe"
        }
    ]
}
```

---

## Compliance Trends

```
GET /dashboard/trends
```

Supports:

```
7 Days

30 Days

90 Days

1 Year
```

Returns trend data suitable for charts.

---

## Risk Distribution

```
GET /dashboard/risks
```

Returns:

```json
{
    "critical": 2,
    "high": 5,
    "medium": 9,
    "low": 14
}
```

---

## Recent Reports

```
GET /dashboard/reports
```

Returns recently generated reports.

---

## Background Jobs

```
GET /dashboard/jobs
```

Returns active processing jobs.

---

## Notifications

```
GET /dashboard/notifications
```

Returns unread notifications for the authenticated user.

# 16.8.10 Performance Requirements

Dashboard endpoints shall:

- Return aggregated data.
- Avoid expensive joins.
- Cache frequently requested metrics.
- Support pagination where applicable.
- Respond within acceptable latency targets.

# 16.8.12 Audit Events

The platform shall record:

- Dashboard Accessed
- Analytics Exported
- Widget Configuration Updated (Future)

Dashboard views shall not expose sensitive organizational information across tenants.

---

# 16.8.13 Security

The Dashboard API shall:

- Enforce tenant isolation.
- Restrict analytics to organization data.
- Prevent exposure of internal AI details.
- Cache only tenant-safe data.
- Protect sensitive metrics.

# 16.8.15 Acceptance Criteria

The Dashboard API shall be considered complete when:

✓ Dashboard metrics are available.

✓ Compliance trends are displayed.

✓ Risk distribution is calculated.

✓ Recent activities are accessible.

✓ Background jobs are visible.

✓ Tenant isolation is enforced.

✓ Frequently accessed metrics are optimized.

# 16.8.16 Summary

The Dashboard & Analytics API provides aggregated organizational insights for LexisGraph by exposing compliance metrics, trends, activity summaries, and operational statistics through optimized, read-only endpoints. It enables users to monitor compliance posture efficiently while maintaining performance, scalability, and secure tenant isolation.
