# 16.3 Organization API

---

# 16.3.1 Purpose

The Organization API provides endpoints for managing organizations (tenants) within the LexisGraph platform. It enables organization administrators to manage organization information, branding, compliance settings, subscription details, and organizational preferences while ensuring complete tenant isolation.

Every business resource within LexisGraph shall belong to exactly one organization.

---

# 16.3.2 Objectives

The Organization API shall:

- Create organizations.
- Retrieve organization information.
- Update organization settings.
- Manage organization preferences.
- Configure compliance settings.
- Manage organization branding.
- Support multi-tenancy.
- Enforce tenant isolation.

# 16.3.6 Endpoints

## Get Current Organization

```
GET /organizations/me
```

Returns the authenticated user's organization.

---

Response

```json
{
  "success": true,
  "data": {
    "id": "...",
    "name": "ABC Technologies Pvt Ltd"
  }
}
```

---

## Get Organization

```
GET /organizations/{organization_id}
```

Returns organization details.

Only members of the organization or Super Administrators may access this endpoint.

---

## Update Organization

```
PATCH /organizations/{organization_id}
```

Updates organization details.

Example Request

```json
{
  "name": "ABC Technologies",
  "industry": "Manufacturing",
  "country": "India"
}
```

---

## Upload Organization Logo

```
POST /organizations/{organization_id}/logo
```

Multipart request.

Supported formats:

- PNG
- JPG
- SVG

Maximum size:

```
5 MB
```

---

## Delete Organization Logo

```
DELETE /organizations/{organization_id}/logo
```

Removes the organization logo.

---

## Archive Organization

```
PATCH /organizations/{organization_id}/archive
```

Archived organizations become read-only.

Data shall not be deleted.

---

## Restore Organization

```
PATCH /organizations/{organization_id}/restore
```

Restores archived organization.

---

## Organization Statistics

```
GET /organizations/{organization_id}/statistics
```

Returns:

```json
{
  "users": 28,
  "policies": 42,
  "reports": 15,
  "pending_analysis": 2
}
```

# 16.3.7 Organization Settings

Organizations may configure:

- Default Language
- Default Timezone
- Default Jurisdiction
- Industry Type
- Report Preferences
- Notification Preferences
- Data Retention Policy

Settings shall be editable only by Organization Administrators.

---

# 16.3.8 Compliance Settings

Organizations may configure:

- Primary Jurisdiction
- Applicable Regulations
- Preferred Report Format
- Compliance Threshold
- Default Review Workflow

Compliance settings shall influence analysis workflows.

---

# 16.3.9 Branding

Organization branding may include:

- Logo
- Company Name
- Report Footer
- Report Header
- Brand Color (Future)

Branding shall appear in generated compliance reports.

---

# 16.3.10 Organization Status

Supported statuses:

```
ACTIVE

ARCHIVED

SUSPENDED

PENDING_VERIFICATION
```

Status transitions shall be audited.

# 16.3.12 Validation Rules

Organization Name

- Required
- Maximum 150 characters

Industry

- Required

Country

- ISO Country Code

Timezone

- IANA Timezone Identifier

Slug

- Unique
- Lowercase
- URL-safe

---

# 16.3.13 Tenant Isolation

Every request shall verify:

- Organization Ownership
- User Membership
- Active Organization Status
- Resource Ownership

Cross-organization access shall be denied.

---

The following events shall be recorded:

- Organization Created
- Organization Updated
- Organization Archived
- Organization Restored

- Compliance Settings Changed
- Organization Administrator Changed

All events shall include:

- Organization ID
- Acting User
- Timestamp
- Previous Values
- New Values

---

# 16.3.16 Security

The Organization API shall:

- Enforce strict tenant isolation.
- Restrict administrative actions.
- Validate organization ownership.
- Protect organization metadata.
- Log all organization-level operations.
- Encrypt sensitive configuration data where applicable.

---

# 16.3.17 Future Enhancements

The Organization API shall support:

- Multiple Business Units

- Subscription & Billing
- Custom Domains
- White-label Branding
- Enterprise Federation

# 16.3.18 Acceptance Criteria

The Organization API shall be considered complete when:

✓ Organizations can be created.

✓ Organization information can be updated.

✓ Compliance settings are configurable.

✓ Branding is supported.

✓ Tenant isolation is enforced.

✓ Organization statistics are available.

✓ Administrative actions are audited.

---

# 16.3.19 Summary

The Organization API provides comprehensive management of tenant organizations within LexisGraph. It establishes the foundation for secure multi-tenant operation by managing organization identity, compliance configuration, branding, and administrative settings while enforcing strict tenant isolation and maintaining complete auditability across all organization-level operations.
