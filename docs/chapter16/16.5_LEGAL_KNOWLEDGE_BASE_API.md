# 16.5 Legal Knowledge Base API

---

# 16.5.1 Purpose

The Legal Knowledge Base API provides endpoints for managing the authoritative legal knowledge repository used by the LexisGraph AI platform. It enables administrators to ingest, validate, update, monitor, and maintain legal documents originating from trusted sources.

The API shall ensure that only verified legal content becomes part of the Knowledge Base used during compliance analysis.

---

# 16.5.2 Objectives

The Legal Knowledge Base API shall:

- Register legal sources.
- Import legal documents.
- Trigger ingestion pipelines.
- Maintain document versions.
- Support legal updates.
- Monitor ingestion jobs.
- Preserve auditability.
- Protect knowledge integrity.

---

# 16.5.7 Endpoints

## Register Legal Source

```
POST /legal/sources
```

Request

```json
{
    "name": "Ministry of Labour",
    "type": "GOVERNMENT_WEBSITE",
    "url": "https://..."
}
```

Response

```json
{
    "success": true,
    "data": {
        "source_id": "uuid"
    }
}
```

---

## List Sources

```
GET /legal/sources
```

Supports:

- Pagination
- Search
- Filtering

---

## Get Source

```
GET /legal/sources/{source_id}
```

Returns source details.

---

## Update Source

```
PATCH /legal/sources/{source_id}
```

Allows updating:

- Name
- URL
- Status
- Update Frequency

---

## Delete Source

```
DELETE /legal/sources/{source_id}
```

Soft deletes a legal source.

---

## Upload Legal Document

```
POST /legal/documents
```

Multipart request.

Fields

```
file

source_id

document_type

jurisdiction
```

Response

```json
{
    "success": true,
    "data": {
        "document_id": "uuid",
        "job_id": "uuid"
    }
}
```

---

## Import From URL

```
POST /legal/import
```

Request

```json
{
    "source_id": "...",
    "url": "https://..."
}
```

Creates a background ingestion job.

---

## Rebuild Knowledge Graph

```
POST /legal/rebuild
```

Triggers complete graph reconstruction.

Super Administrator only.

---

## Reindex Embeddings

```
POST /legal/reindex
```

Recreates vector embeddings.

Runs as a background job.

---

## List Legal Documents

```
GET /legal/documents
```

Supports:

- Search
- Pagination
- Jurisdiction
- Status
- Source

---

## Get Legal Document

```
GET /legal/documents/{document_id}
```

Returns document metadata.

---

## Get Ingestion Status

```
GET /legal/jobs/{job_id}
```

Returns:

```json
{
    "status": "PROCESSING",
    "progress": 67
}
```

# 16.5.10 Validation

Legal documents shall be validated for:

- Supported format
- Source authenticity
- Duplicate detection
- OCR quality
- Parsing success
- Metadata completeness

Invalid documents shall not enter the Knowledge Base.

- Source Deleted

# 16.5.15 Security

The Knowledge Base API shall:

- Accept only authorized administrators.
- Validate trusted sources.
- Prevent duplicate imports.
- Store original documents securely.
- Verify document integrity.
- Log every administrative operation.

✓ Embeddings can be regenerated.

# 16.5.18 Summary

The Legal Knowledge Base API provides secure administration of the LexisGraph legal repository. It enables trusted legal content to be imported, validated, transformed into graph and vector representations, and maintained over time while ensuring integrity, traceability, and controlled administrative access.
