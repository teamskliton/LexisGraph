# 16.2 User Management API

---

# 16.2.1 Purpose

The User Management API provides endpoints for creating, retrieving, updating, and managing user accounts within LexisGraph. It enables administrators to manage organization members while allowing users to maintain their own profiles.

The API shall enforce role-based permissions, tenant isolation, and secure account management.

---

# 16.2.2 Objectives

The User Management API shall:

- Manage user profiles.
- Invite organization members.
- Update user information.
- Manage user roles.
- Activate or deactivate accounts.
- Retrieve user information.
- Support profile management.
- Enforce RBAC.

# 16.2.6 Endpoints

## Get Current User

```
GET /users/me
```

Returns the authenticated user's profile.

---

Response

```json
{
    "success": true,
    "data": {
        "id": "...",
        "full_name": "John Doe",
        "email": "john@example.com",
        "role": "ORG_ADMIN"
    }
}
```

---

## Update Profile

```
PATCH /users/me
```

Request

```json
{
    "full_name": "John Doe Updated"
}
```

---

Response

```json
{
    "success": true,
    "message": "Profile updated successfully."
}
```

---

## Change Password

```
PATCH /users/me/password
```

Request

```json
{
    "current_password": "CurrentPassword123!",
    "new_password": "NewPassword123!"
}
```

---

Response

```json
{
    "success": true,
    "message": "Password updated successfully."
}
```

---

## List Users

```
GET /users
```

Permissions

```
ORG_ADMIN

SUPER_ADMIN
```

Supports:

- Pagination
- Search
- Sorting
- Filtering

---

Query Parameters

```
?page=1

&page_size=20

&search=john

&role=COMPLIANCE_OFFICER

&status=ACTIVE
```

---

## Get User

```
GET /users/{user_id}
```

Returns details for a specific user.

---

## Invite User

```
POST /users/invite
```

Request

```json
{
    "email": "employee@example.com",
    "role": "REVIEWER"
}
```

---

Response

```json
{
    "success": true,
    "message": "Invitation sent successfully."
}
```

---

## Update User

```
PATCH /users/{user_id}
```

Allows administrators to update:

- Name
- Role
- Status

---

Request

```json
{
    "role": "COMPLIANCE_OFFICER",
    "status": "ACTIVE"
}
```

---

## Delete User

```
DELETE /users/{user_id}
```

Soft deletes a user account.

The platform shall retain audit history.

---

Response

```json
{
    "success": true
}
```

---

## Deactivate User

```
PATCH /users/{user_id}/deactivate
```

Deactivated users shall not be able to authenticate.

---

## Activate User

```
PATCH /users/{user_id}/activate
```

Restores account access.

# 16.2.13 Audit Events

The following events shall be logged:

- User Created
- User Invited
- User Activated
- User Deactivated
- User Updated
- User Deleted
- Role Changed
- Password Changed
- Profile Updated

Audit records shall include the acting user and timestamp.

---

# 16.2.14 Security

The User Management API shall:

- Enforce RBAC.
- Prevent privilege escalation.
- Validate organization ownership.
- Prevent cross-tenant access.
- Protect personal information.
- Log all administrative actions.

# 16.2.16 Acceptance Criteria

The User Management API shall be considered complete when:

✓ Users can manage their profiles.

✓ Administrators can invite users.

✓ Administrators can manage user accounts.

✓ RBAC is enforced.

✓ Tenant isolation is maintained.

✓ Audit logs capture all user management actions.

✓ Soft deletion preserves historical records.

---

# 16.2.17 Summary

The User Management API provides comprehensive lifecycle management for LexisGraph users, enabling secure profile management, administrative user operations, role assignment, and account lifecycle control. Through strict role-based authorization, tenant isolation, and detailed auditing, the API ensures secure and accountable management of organizational users.
