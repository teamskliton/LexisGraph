# Design Principles

## 1. Information First

Every pixel must communicate useful information.

Avoid decorative UI that does not improve understanding.

---

## 2. Enterprise Simplicity

Reduce visual noise.

Do not remove useful information.

---

## 3. One Primary Action

Every screen has one dominant action.

Examples:

Dashboard → Run Compliance

Chat → Ask AI

Upload → Upload Document

Reports → Generate Report

---

## 4. Consistency Over Creativity

Never invent a new card style or button style for a single page.

---

## 5. Dark Mode First

Dark theme is the primary experience.

Light mode is secondary.

---

## 6. Performance Is UX

Avoid unnecessary animations.

Avoid unnecessary rendering.

Prefer server components whenever possible.

---

## 7. Explainability

AI decisions must always show supporting evidence.

Compliance reports should never feel like black-box outputs.
