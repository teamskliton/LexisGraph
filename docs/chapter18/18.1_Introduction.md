# 18.1 Introduction

---

## 18.1.1 Purpose

The backend of LexisGraph serves as the core processing layer responsible for implementing the business logic, managing data storage, coordinating AI-powered compliance analysis, and exposing secure APIs to the frontend. It integrates modern web technologies with GraphRAG techniques to automate regulatory gap analysis by processing legal regulations and organizational policy documents.

The backend follows a modular service-oriented architecture, allowing each component to perform a dedicated responsibility while ensuring scalability, maintainability, and ease of future enhancement.

---

## 18.1.2 Objectives

The backend is designed to achieve the following objectives:

- Provide secure RESTful APIs for frontend communication.
- Authenticate and authorize users using Role-Based Access Control (RBAC).
- Manage organizations, users, and policy documents.
- Process uploaded documents through an AI-powered pipeline.
- Build and maintain knowledge graphs from legal documents.
- Perform GraphRAG-based contextual retrieval.
- Generate explainable compliance reports.
- Support asynchronous background processing.
- Ensure reliable, scalable, and secure system operation.

---

## 18.1.3 Backend Responsibilities

The backend is responsible for:

- User authentication and session management.
- Organization management.
- Policy document management.
- Document preprocessing and text extraction.
- Clause and entity extraction.
- Knowledge graph construction.
- Vector embedding generation.
- GraphRAG retrieval.
- AI-assisted compliance analysis.
- Report generation.
- Data persistence.
- Background job execution.
- Logging and monitoring.

---

## 18.1.4 Technology Overview

The backend is developed using modern open-source technologies.

| Component | Technology |
|------------|------------|
| Framework | FastAPI |
| Language | Python 3.12+ |
| ORM | SQLAlchemy |
| Database | PostgreSQL |
| Graph Database | Neo4j |
| Vector Database | Qdrant |
| Cache | Redis |
| AI Model | Gemini 2.5 Flash |
| Workflow Engine | LangGraph |
| Retrieval Framework | LlamaIndex |
| Authentication | JWT |
| Containerization | Docker |

Each technology has been selected based on performance, scalability, and compatibility with the GraphRAG architecture.

The overall backend workflow is illustrated below.

```
Frontend Request

↓

Authentication

↓

API Endpoint

↓

Business Logic

↓

↓

↓

↓
```
